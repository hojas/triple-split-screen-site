功能

为竖屏视频做的三块屏

不是简单的三份复制：同帧、可拖动、不挡画面、站点抢样式也不怕。

自动识别竖屏视频

按视频原始分辨率判断（高 > 宽），横屏视频自动排除，不会误伤页面上的其他视频。

穿透 shadow DOM

会钻进 open shadow root 里找 <video>，Web Components 播放器同样能识别。

三种开启方式

扩展图标弹窗开关、快捷键 Alt+Shift+3、视频上右键「用三分屏播放这个视频」。

2 / 3 / 4 屏，三种布局

页面内（贴着原视频）、影院（铺满窗口）、真全屏。超宽屏和双屏用户不必忍受被压扁的三画面。

三画面严格同帧

每帧只从 <video> 抓一次图到离屏画布，再 blit 出三份，绝不会出现三块画面不同步。

控制条不挡画面

空闲 3 秒后完全消失（不吃点击），指针一动立刻恢复；位置和展开状态都会记住。

盖得住，也抢不走

画布在 Top Layer + z-index 2147483647；站点强行改 video 样式也会被回写纠正。

多 frame 与自动开启

视频在 iframe 里也能识别；勾选「在此站点自动开启」，下次打开直接进三分屏。

FAQ

常见问题

支持哪些浏览器？

Chrome / Edge 等 Chromium 内核浏览器（Manifest V3）。

购买后怎么拿到 License？

付款后订单页会直接显示卡密（License），也可以在平台的「订单查询」里随时翻出来。拿到后到「授权管理」页粘贴即可查看状态、激活本机或解绑设备。

一个 License 能用几台设备？

默认 3 台。换电脑或重装系统时，先在授权管理页解绑旧设备，再在新设备上激活即可。

会把我看的视频上传吗？

不会。分屏完全在本地浏览器里用 canvas 完成，视频数据不上传。扩展只在授权校验时联网：首次启动登记试用、粘贴授权码激活，以及之后每 12 小时复核一次吊销 / 换机状态；只发送授权码、派生的本机设备码，以及一个随机的试用设备标识（存在授权服务域名的 Cookie 里，用于让试用不因重装而重置），不采集硬件信息。

首发期推广价，优惠结束后恢复原价。已经购买的 License 不受影响。
