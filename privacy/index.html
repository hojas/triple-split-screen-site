隐私政策

本政策说明「三分屏 · Triple Split Screen」浏览器扩展（下称“本扩展”）及官网在你使用过程中如何处理数据。

生效日期：2026 年 10 月 19 日 · 最近更新：2026 年 10 月 19 日

要点摘要

  • 视频画面只在你本机的浏览器里处理：不录制、不下载、不上传。
  • 不收集浏览历史，不记录按键内容、鼠标轨迹或点击行为，不做用户画像、不投放广告、不出售数据。
  • 唯一的联网请求发往我们自己的授权服务器，只用于校验试用与授权。
  • 安装后可免费试用 3 天；试用结束后输入授权码即可继续使用。

1. 我们处理哪些数据

1.1 仅在本机处理、不会上传的数据

  • 网页上正在播放的竖屏视频的画面、尺寸与播放状态：用于在本地 canvas 上绘制 2 / 3 / 4 块严格同帧的画面。视频帧只在内存中短暂存在，不录制、不下载、不保存、不上传。
  • 当前页面的域名：用于判断你是否在该站点勾选了「在此站点自动开启」，以及视频被替换、页面切换时自动跟随。域名不上传，也不会被整理成访问记录。
  • 你的界面操作（拖动控制条、展开设置、切换分屏数量）：只用于实时交互，不记录、不上报。

1.2 仅保存在你本机（chrome.storage.local）的数据

  • 扩展设置：分屏数量、页面内 / 影院 / 全屏布局、镜像、间距、圆角、背景、填充方式、是否显示页面内控制条，以及「自动开启」的站点列表。
  • 控制条的位置与展开状态（记住上次放在哪、是否展开）。
  • 授权相关：授权码、由随机安装 ID 派生的设备 ID、设备标签（例如 macOS / Windows）、授权或试用快照（授权对象、套餐、功能、有效期、最近校验时间）、试用起止时间、随机安装 ID、设备锚点、时钟偏移。
  • 以上数据保存在你的浏览器本地，卸载扩展或清除扩展数据后即被删除。

1.3 发送到授权服务器的数据

本扩展唯一的联网请求，是向我们的授权服务（https://triple-split-screen-license.netlify.app）登记试用、校验授权码、激活或解绑本机：

  • 试用登记：随机生成的设备锚点、首次使用时间、产品标识。
  • 授权校验 / 激活 / 解绑：授权码、由安装 ID 派生的设备 ID、操作系统类型（例如 “Chrome 扩展 · macOS”）、产品标识。
  • 这些请求不包含页面内容、视频画面、页面 URL 或浏览历史。
  • 请求时机：扩展启动、约每 12 小时一次自动复核、试用窗口复核（默认约 6 小时）、你点击「重新校验」，以及激活或解绑本机时。
  • 授权码由我们签发，其中可能包含签发时填写的授权对象名称或邮箱（例如购买时填写）。它只用于识别授权、在扩展里展示授权状态，以及客服排查问题。

1.4 官网「授权管理」页

官网的授权管理页用于查询、激活、解绑授权。你在该页输入的授权码、页面生成的设备 ID 会保存在该页面的 localStorage，并在你点击操作时发送到上述授权服务器。该页面同样适用本政策。

2. Cookie

  • 本扩展会在授权服务域名下写入一个 Cookie，名为 tss_dev，内容是随机设备锚点与首次 / 最近使用时间。它的唯一用途是：卸载重装扩展后仍能识别同一台设备的试用起点，避免试用被重复重置。
  • 该 Cookie 为 httpOnly，网页脚本读取不到；只有本扩展通过浏览器提供的 Cookie 接口读写。我们不读取或写入任何其他网站的 Cookie，也不把 Cookie 内容用于广告或用户画像。
  • 官网不使用广告 Cookie 或统计 Cookie。

3. 我们不做的事

  • 不收集或保存浏览历史；
  • 不记录按键内容、鼠标轨迹或点击行为（控制条的显示 / 隐藏只是实时响应，不记录、不上报）；
  • 不读取页面文字、表单内容或密码，不读取其他网站的 Cookie；
  • 不注入广告，不做用户画像，不将数据用于信用评估或借贷；
  • 不出售、不出租用户数据；除法律法规要求，或为提供授权服务所必需的基础设施服务商外，不向第三方共享你的数据。

5. 数据保留与安全

  • 本地数据：保留到你卸载扩展或清除扩展数据为止。
  • 服务器数据：试用锚点、授权与激活记录，在提供授权服务所必需的期限内保留（用于试用防刷、授权校验、解绑换机与客服排查），你可以随时联系我们提前删除。

  • 授权服务运行在 Netlify 平台上，平台可能记录请求日志（IP、时间、User-Agent），保留期限由平台政策决定。
